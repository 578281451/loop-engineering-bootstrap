# Lightweight Patterns

Generated projects may use these bounded patterns:

- feature development: acceptance first, implementation, unit/integration tests, E2E when user-facing;
- bug fix: reproduce, identify root cause, regression test, fix, verify;
- frontend E2E: route, data, browser, viewport, actions, assertions, artifact;
- code review: inspect diff, run focused checks, report findings by severity;
- documentation sync: update source-of-truth docs and validate references.

Patterns are task starters, not permissions to bypass gates or host rules.
